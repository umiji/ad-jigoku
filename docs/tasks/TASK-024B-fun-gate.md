# TASK-024B — 面白さゲート（プレイテスト実施・判定）

- Milestone: M4 / Phase 1
- Depends on: 024, 024A
- Size: 1 session（ただし実施内容はコードではなくプレイテストの運営・記録）
- **DECISIONS_v0.2.md §7 により新設**

## Objective

「遊ぶ → 結果 → もう一回」が初めて成立する地点（TASK-024 完了時点）で、実際にプレイテストを行い、
Phase 1 の続行可否を判定する。**このタスクにコードは含まれない。**

## Context

`DECISIONS_v0.2.md §7`。GAME §25 Phase 1 の目的は「本当に面白いか検証」すること
（GAME §1.1「UX 検証ツールをゲームと呼んではいけない」）。この判定を経ずに M5/M6 へ進むことを
禁止する。

## 手順

1. **5人以上**に、事前説明なしでプレイしてもらう
2. 記録する項目:
   - GAME §24 Fun 節の5項目
   - **2回目プレイ率**（初回終了後、自発的にもう一度プレイした割合）
   - 「何のゲームか」を30秒以内に言語化できたか
3. 結果を `docs/playtest/YYYY-MM-DD-fun-gate.md` 等、日付付きの記録として残す
   （テンプレートはこのタスク内で用意してよい）

## 通過条件（Q2、初期値。オーナーが調整可）

- 2回目プレイ率 **≥ 60%**
- 「何のゲームか」を30秒以内に言語化できる

## 不通過時の対応

- **M5/M6 に進まない**
- テンプレート（`GAME_ENGINE_DESIGN.md §8.2`）・threat 値（同 §9.4）・摩擦値（`FRICTION_CAP` /
  `LOAD_BUDGET`、Q1）の調整に戻る
- 調整だけで説明がつかない場合は `docs/design/DECISIONS_v0.2.md` の改訂を提案する
  （設計と実装が矛盾したときの原則、`CLAUDE.md` §3）

## Acceptance criteria

- [ ] 5人以上のプレイテスト記録が残っている
- [ ] 2回目プレイ率と言語化可否が記録されている
- [ ] 通過/不通過の判定結果が明記されている
- [ ] 不通過の場合、次の調整アクション（テンプレート/threat/摩擦値のどれを触るか）が記録されている

## Definition of Done

- 通過と判定された場合のみ、M5（TASK-029〜）に着手してよい
- 不通過の場合、本タスクは「調整して再実施」の状態で残り、再実施の記録を追記する形でクローズする
