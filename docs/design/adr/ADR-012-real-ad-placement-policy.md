# ADR-012: 実広告はコンテンツページのみ、ゲーム/LPは偽物のみ

- Status: Accepted
- Date: 2026-09-12
- Drivers: D9（`DECISIONS_v0.2.md` §8.1）

## Context

本プロダクトは広告のダークパターンを批判する立場であり、CLAUDE.md §2.2 / ADR-007 の通り
「自分がダークパターンをやった瞬間に信用が死ぬ」。一方で PRODUCT §31 は `Ads = Bad` ではなく
`User-hostile Ad UX = Bad` という立場を取っており、プロダクト自体が広告収益を得ることと矛盾しない。
記事・ランキング・図鑑・レポートのようなコンテンツページに実広告を掲載すること自体は、
プロダクトの主張と矛盾しない一方、**ゲーム/LP に実広告ネットワークを混ぜると、プレイヤーが
「本物の広告」と「ゲーム内の偽広告」を区別できなくなり、批判対象と同じ行為をすることになる**。

## Decision

実広告ネットワークの配置を、ルート種別で明確に分離する。

```text
ゲーム / LP ルート                          : 実広告ネットワーク禁止（偽クリエイティブのみ） ← SAFE-13
記事 / ランキング / 図鑑 / レポート ルート    : 実広告可。お行儀のよい配置のみ
```

- `AdSlot` コンポーネントに `provider: 'simulated' | 'network'` を持たせ、ルート種別で `network` を
  型・テストで拒否する（新規 **SAFE-13**）
- ネットワークは AdSense より**アフィリエイト（自前クリエイティブ）を優先**する（誤クリック BAN の
  仕組みがないため）
- **自己診断スコアを公開する**: 自サイトを自分の診断にかけ、結果を掲げる。PRODUCT §31 の実演
- 要件文書を改訂: GAME §2.3 / §17 の「実広告ネットワークのコードを入れない」を
  「**ゲーム内では**入れない」に限定する

## Consequences

### 良い

- 「批判対象と同じ行為をしていない」ことを構造（型・CSP・静的検査）で保証できる
- コンテンツページの広告収益とプロダクトの主張が両立する
- 自己診断スコアの公開が PRODUCT §31 の具体的な実演になり、信頼性の裏付けになる

### 悪い

- ルート種別ごとの権限管理が新たに必要になり、実装・レビューの負荷が増える
- 「ゲーム/LP は完全に偽物」の境界線をコンテンツ運用側が誤って越えるリスクが残る

### 緩和

- SAFE-13 を CSP + ルート単位の静的検査で CI 強制する（`ARCHITECTURE.md §11`）
- `AdSlot.provider` の許可値をルートごとに型レベルで制限する
