# ADR-012: 実広告配置ポリシー

- Status: Accepted
- Date: 2026-09-12
- Drivers: DECISIONS_v0.2.md §8.1（D9）

## Context

プロダクトは広告のダークパターンを批判する立場であり、ゲーム/LP に実広告ネットワークを入れることは
できない（GAME §2.3, §17、AD-9、SAFE-13）。一方でプロダクト自体の収益化には広告掲載も選択肢になり得る。
「実広告は一切扱わない」と「収益源として広告を検討する」の間で線引きが必要だった。

## Decision

ルート種別で実広告の可否を分ける。

```text
ゲーム / LP ルート      : 実広告ネットワーク禁止（偽クリエイティブのみ）   ← SAFE-13 で強制
記事 / ランキング / 図鑑 / レポート : 実広告可。お行儀のよい配置のみ
```

- `AdSlot` コンポーネントに `provider: 'simulated' | 'network'` を持たせ、ゲーム/LP ルートでは
  `network` を型・テストで拒否する
- ネットワーク広告（AdSense 等）より**アフィリエイト（自前クリエイティブ）を優先**する。誤クリック
  による BAN の仕組みがないため
- **自己診断スコアを公開する**: 自サイトを自分の診断にかけ「広告を掲載していて Score 12/100」を
  掲げる。`PRODUCT_REQUIREMENTS.md` §31（Ads = Bad ではない）の実演にする
- 要件文書を改訂: `GAME_REQUIREMENTS.md` §2.3 / §17 の「実広告ネットワークのコードを入れない」は
  「ゲーム内では入れない」に限定する

## Consequences

### 良い
- プロダクトの批判対象（ダークパターン）と収益化手段を明確に分離できる
- 自己診断スコアの公開により、「広告を掲載しても Ads = Bad ではない」という主張を自らのサイトで
  実演できる

### 悪い
- ルート種別ごとの型・CSP・静的検査を追加で維持する必要がある（SAFE-13）
- 記事ルートに実広告を出す以上、その配置自体がプロダクトの評価基準に照らして「お行儀がよい」ことを
  自分自身で満たし続ける説明責任が生じる

### 却下した案
- サイト全体で実広告を一切扱わない: 収益化手段を自ら断つことになる
- ゲーム内にも実広告を許可する: プロダクトの批判対象と自己矛盾する（AD-9 に違反）
