# AMIX_DESIGN_REFERENCE.md

## 1. Purpose

本ドキュメントは、AMIXのWebサイト／ブラウザゲーム群を本プロジェクトのデザインベンチマークとして分析し、
「何を借りるか」「何を借りないか」を実装可能な設計原則に落とすためのリファレンスである。

Primary references:
- AMIX GAMES: https://amix-design.com/tl/web-g-games/
- AMIX TOWN: https://amix-design.com/tl/town/about.html
- Motion & WebGL Gallery: https://amix-design.com/tl/web-motion/
- AMIX Web Tools: https://amix-design.com/tools
- AMIX Fun/Entertainment: https://amix-design.com/tools/fun

## 2. AMIXから学ぶべき本質

### 2.1 「Webサイト」ではなく「体験」を入口にする

AMIX TOWNは、情報を単にスクロールして読ませるのではなく、
「歩く」「住人と話す」「建物に入る」「遊ぶ」という行動に変換している。

本プロジェクトでもLPを「説明ページ」として設計しない。

> 説明を読む → 広告地獄を体験する

に変換する。

### 2.2 UIそのものを世界観にする

AMIX TOWNでは3D空間とサイトUIの境界が薄い。
AMIX GAMESでもゲーム機・カートリッジのようなメタファーをサイト全体に使っている。

本プロジェクトでは、

> 「広告ポップアップそのものがナビゲーションUI」

とする。

説明カード、CTA、注意書き、次のセクションへの導線まで、
「広告地獄で実際に出てきそうな広告UI」の形式にする。

### 2.3 きちんと作る × ふざける

AMIXはコンセプトがユーモラスでも、タイポグラフィ、余白、モーション、グラフィック処理は雑にしない。

本プロジェクトの方向性も、

> 本気でふざける。

とする。

「広告地獄」という馬鹿げたテーマを、
安っぽいネタサイトではなく、デザインスタジオ品質で見せる。

### 2.4 Browser-first / Instant interaction

AMIX GAMESはインストール・登録なしでURLから即プレイできることを強く打ち出している。
本プロジェクトもLP→ゲーム→診断の導線で摩擦を作らない。

原則:
- まず触れる
- 読ませすぎない
- 登録を要求しない
- クリック／タップ直後に反応する
- モバイルを第一級の体験として扱う

### 2.5 Motionを装飾ではなく情報設計に使う

AMIXのMotion & WebGL Galleryではスクロール、タイムライン、タイポグラフィ、グリッド、グリッチ等を
「技術をどう魅力的に見せるか」というデザイン要素として扱っている。

本プロジェクトではモーションを、

- 広告が突然出る
- 広告が重なる
- 閉じるまで待たされる
- 閉じたら次の広告が出る
- スクロールすると別の広告が侵入する

という「広告地獄の体験」に変換する。

## 3. 借りるもの

### MUST
- 強いファーストビュー
- 大きなタイポグラフィ
- 暗い背景と高コントラスト
- 余白を使った高級感
- スクロールに意味を持たせる
- モーションの品質
- UIを世界観に統合
- 体験して理解させる
- モバイルファースト
- 軽量なWeb体験

### SHOULD
- 3D／WebGLは必要な箇所だけ
- グリッチ、粒子、ノイズ等の演出
- セクションごとの小さな発見
- 隠し要素
- 1ページ内でのゲーム的な回遊

## 4. 借りないもの

- AMIXそのもののビジュアルコピー
- ボクセルをそのまま流用
- 固有のロゴ、キャラクター、素材
- 「おしゃれだから」という理由だけの3D
- 技術デモを目的化すること
- 情報量を増やすための装飾
- ただのゲームLP化

## 5. 本プロジェクトへの翻訳

| AMIXの考え方 | 本プロジェクト |
|---|---|
| 歩いて出会う | スクロールして広告に遭遇する |
| 建物に入る | ポップアップを開く／閉じる |
| 住人と話す | 広告の説明文を読む |
| ミニゲーム | 広告を消す操作 |
| 世界を探索 | 広告地獄の深部へ進む |
| WebGL/Motion | 広告出現・重なり・消滅演出 |
| ゲームUI | 広告UIをナビゲーションにする |

## 6. 一番重要な示唆

AMIXの強さは「おしゃれなサイト」ではなく、

> コンセプトと操作とビジュアルが同じ方向を向いている

ことにある。

本プロジェクトでは、

> 「広告地獄」というコンセプト
> ↓
> 「広告ポップアップを消す」という操作
> ↓
> 「広告ポップアップで説明する」というUI
> ↓
> 「閉じるほど先に進む」というナビゲーション

を一本化する。

これをデザインの中核とする。
